# Overview

The first activity in Week 02 focuses on **Dataset Discovery**, where multiple public datasets are explored and evaluated before selecting the primary dataset for analysis.

Instead of immediately choosing a dataset, several candidates were collected from different public sources. This approach ensures that the selected dataset is suitable for the objectives of the project and supports the complete Data Analysis workflow.

---

# Objectives

The objectives of this activity are:

- Understand the importance of data collection.
- Explore public dataset repositories.
- Compare multiple datasets.
- Select a dataset suitable for further analysis.
- Document the dataset selection process.

---

# Data Sources

Three public datasets were collected for evaluation.

| No | Dataset | Source | Records | Topic |
|----|---------|--------|---------|-------|
| 1 | Sample - Superstore | Kaggle | 9,994 | Retail / Sales |
| 2 | Product-Sales-Region | ExcelX | 1,500 | Product Sales / Retail |
| 3 | 100000 Sales Records | Excel BI Analytics | 100,000 | Sales |

---

# Dataset Evaluation

Each dataset was evaluated based on:

- Relevance to business analysis
- Number of records
- Feature completeness
- Data structure
- Potential for visualization
- Suitability for future project development

---

# Selected Dataset

After comparing the available datasets, the **100000 Sales Records** dataset was selected as the primary dataset for this project.

Reasons for selection:

- Largest number of records.
- Well-structured tabular data.
- Suitable for descriptive analysis.
- Supports statistical analysis.
- Suitable for dashboard development.
- Can be used throughout the remaining weeks of the Industry Simulation Program.

# Key Findings

- Public datasets can be obtained from various trusted sources such as Kaggle, ExcelX, and Excel BI Analytics.
- Dataset characteristics vary significantly in terms of size and available features.
- Choosing the appropriate dataset is an important step before starting any data analysis process.

---

# Challenges

During dataset evaluation, one candidate dataset was found to be a duplicate of another dataset in a different file format. To ensure diversity in comparison, it was replaced with a different retail sales dataset from another public source.

---

# Conclusion

Dataset Discovery was successfully completed.

Three datasets were identified, evaluated, and compared based on predefined criteria. One dataset was selected as the primary dataset for the project and will be used throughout the subsequent stages, beginning with Data Collection and Data Understanding.
